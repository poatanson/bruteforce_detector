# SSH 브루트포스 의심 IP 탐지기

`auth.log`에서 SSH 로그인 실패 기록을 집계하여, 짧은 시간 안에 시도를 몰아서 한 IP를 **브루트포스 의심 IP**로 판정하고 JSON 파일로 저장하는 Python 스크립트입니다.

외부 라이브러리 없이 표준 라이브러리만 사용합니다. (Python 3.7+)

## 주요 기능

- **슬라이딩 윈도우 탐지**: IP별로 최근 N초(기본 5분) 안의 실패 횟수를 추적하고, 최대값(peak)이 임계치(기본 10회) 이상이면 의심 IP로 판정합니다.
- **다양한 로그 형식 지원**
  - 전통 syslog: `Jan 12 03:14:15 host sshd[1234]: ...`
  - ISO-8601: `2024-01-12T03:14:15+09:00 host sshd[1234]: ...`
  - OpenSSH 9.8+ 의 `sshd-session` 프로세스명
  - 로테이션된 `.gz` 파일
- **유저명 위조 방어**: 유저명은 공격자가 마음대로 정할 수 있으므로, 한 줄에서 *마지막* `from <ip> port <n>`을 실제 접속 정보로 사용합니다. (유저명에 가짜 IP를 심어도 속지 않습니다.)
- **중복 집계 방지**: sshd는 존재하지 않는 계정에 대해 `Invalid user` 와 `Failed ... for invalid user` 를 연달아 남기는데, 같은 연결(IP + 포트)의 첫 번째 중복 한 건만 건너뜁니다.
- **IPv4 / IPv6 지원**: IPv4-mapped IPv6 주소는 IPv4로 정규화합니다.
- **내부 IP 제외**: 루프백·미지정·멀티캐스트는 항상, 사설·링크로컬 IP는 기본적으로 제외합니다.
- **안전한 저장**: 임시 파일에 쓴 뒤 교체(atomic write)하므로 중간에 실패해도 기존 결과가 깨지지 않습니다.
- **메모리 보호**: IP당 유저명 저장(최대 200개)과 중복 제거 기억(최대 10,000건)에 상한이 있습니다.

## 슬라이딩 윈도우로 오탐 줄이기

단순히 "파일 전체에서 실패 N회 이상이면 차단"하는 방식은 오탐이 잦습니다. 몇 달 치 로그가 쌓인 파일에서는 비밀번호를 가끔 틀리는 정상 사용자도 누적 횟수가 임계치를 넘기 때문입니다.

이 스크립트는 **누적 횟수가 아니라 "짧은 시간 안에 몰린 횟수"** 로 판정합니다.

| 상황 | 누적 횟수 방식 | 슬라이딩 윈도우 방식 (5분 / 10회) |
| --- | --- | --- |
| 정상 사용자가 한 달 동안 하루 1~2번씩 오타 (총 40회) | 의심 IP로 **오탐** | 5분 안에 1~2회뿐이라 **정상** |
| 공격자가 3분 동안 사전 대입 공격 (총 60회) | 의심 IP | 5분 안에 60회라 **의심 IP** |

### 동작 방식

1. IP마다 최근 실패 시각을 담는 큐(`deque`)를 하나씩 유지합니다.
2. 새 실패가 들어오면 큐에 시각을 추가하고, 윈도우(기본 300초)보다 오래된 시각은 앞에서부터 제거합니다.
3. 그 시점의 큐 길이가 해당 IP의 윈도우 내 시도 횟수입니다. 이 값의 **최대값(peak)** 을 기록합니다.
4. 로그 전체를 읽은 뒤 peak가 임계치 이상인 IP만 의심 IP로 판정합니다.

### 오탐을 줄이는 추가 장치

- **중복 집계 방지**: `Invalid user` 와 `Failed ... for invalid user` 가 같은 연결에서 연달아 남아도 한 번만 셉니다. 실제보다 시도 횟수가 부풀려져 임계치를 넘는 일을 막습니다.
- **시간 역행 보정**: DST 전환 등으로 로그 시각이 거꾸로 가면 직전 시각으로 고정해, 윈도우가 비정상적으로 늘어나 오탐이 생기는 것을 막습니다.
- **내부 IP 제외**: 루프백·사설 IP 등 내부 트래픽은 기본적으로 탐지 대상에서 뺍니다.
- **판정 근거 기록**: 결과의 `peak_window`에 판정 근거가 된 구간(시도 횟수, 시작/끝 시각)을 남겨, 의심 IP가 왜 걸렸는지 바로 검증할 수 있습니다.

> 오탐이 얼마나 줄어드는지는 환경마다 다릅니다. 윈도우(`-w`)와 임계치(`-t`)를 서버의 정상 로그인 패턴에 맞게 조정하세요.

## 집계 대상

| 이벤트 | 설명 |
| --- | --- |
| `Failed password` | 비밀번호 인증 실패 |
| `Failed publickey` | 공개키 인증 실패 |
| `Failed keyboard-interactive/pam` | 키보드 인터랙티브(PAM) 인증 실패 |
| `Invalid user` | 존재하지 않는 계정으로 시도 |

## 사용법

```bash
# 기본 실행 (auth.log 분석 → malicious_ip.json 저장)
python3 detect_bruteforce.py

# 로그 파일과 출력 파일 지정
python3 detect_bruteforce.py /var/log/auth.log -o malicious_ip.json

# 윈도우 10분, 임계치 20회로 조정
python3 detect_bruteforce.py auth.log -w 600 -t 20

# 로테이션된 gz 로그 분석
python3 detect_bruteforce.py auth.log.2.gz
```

> 스크립트 파일명은 실제 저장한 이름으로 바꿔서 사용하세요.

## 옵션

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `log_file` | `auth.log` | 분석할 로그 파일 (`.gz` 가능) |
| `-o`, `--output` | `malicious_ip.json` | 결과 JSON 저장 경로 |
| `-w`, `--window` | `300` | 슬라이딩 윈도우 크기(초) |
| `-t`, `--threshold` | `10` | 윈도우 내 임계 시도 횟수 |
| `--include-private` | 꺼짐 | 사설/링크로컬 IP도 분석에 포함 |
| `--reference-date` | 파일 mtime | syslog 형식의 연도 추정 기준 시각 (ISO 형식) |

## 출력 예시

```json
{
  "203.0.113.45": {
    "count": 152,
    "first_seen": "2024-01-12T03:10:02",
    "last_seen": "2024-01-12T04:51:37",
    "usernames": ["admin", "oracle", "root", "test"],
    "peak_window": {
      "attempts": 38,
      "start": "2024-01-12T03:10:02",
      "end": "2024-01-12T03:14:48"
    }
  }
}
```

| 필드 | 기준 | 설명 |
| --- | --- | --- |
| `count` | 파일 전체 | 해당 IP의 총 실패 횟수 |
| `first_seen` / `last_seen` | 파일 전체 | 첫 / 마지막 시도 시각 |
| `usernames` | 파일 전체 | 시도한 유저명 목록 (정렬됨) |
| `peak_window` | 판정 근거 구간 | 윈도우 내 최대 시도 횟수와 그 구간의 시작/끝 |
| `usernames_truncated` | - | 유저명이 상한(200개)을 넘어 잘렸을 때만 `true` |

결과는 `peak_window.attempts`가 큰 순서로 정렬됩니다.

## 실행 결과 및 종료 코드

실행하면 처리 요약이 출력됩니다.

```
총 12034줄 중 842줄 매칭 (제외 IP 12, 중복 건너뜀 97, IP 오류 0, 시간 파싱 실패 0)
3개의 의심 IP를 malicious_ip.json 에 저장했습니다.
```

| 종료 코드 | 의미 |
| --- | --- |
| `0` | 정상 종료 |
| `1` | 로그 파일을 읽을 수 없음 |
| `2` | 매칭된 라인이 0건 (로그 형식 또는 프로세스명 확인 필요) |

## 주의사항

- **타임존**: ISO-8601 로그의 오프셋은 버리고 로그에 적힌 시각을 그대로 사용합니다.
- **연도 추정**: syslog 형식에는 연도가 없어 파일 수정 시각(또는 `--reference-date`)을 기준으로 추정합니다. 기준보다 하루 넘게 미래로 계산되면 작년 로그로 간주합니다.
- **탐지 범위**: 로그인 *실패*만 집계합니다. 성공한 로그인은 판정에 포함되지 않습니다.
- **차단 기능 없음**: 이 스크립트는 탐지와 기록만 수행하며, 방화벽 차단은 하지 않습니다.
